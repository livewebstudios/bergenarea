Home page popup: how to use this editor

This editor controls the popup card that opens on the website. Only the webmaster login can open it.

Logging in

Bookmark this editor: /admin/notice/. Log in with the committee email and password you set from the invite email. The committee login is shared by whoever holds the position, so nobody's own name ever shows on the site or in its history.

Put up a new popup

  1. Open Home page popup.
  2. Turn On on.
  3. Write a short title and message. Add a button label and link if people should go somewhere.
  4. Pick the first and last day it shows.
  5. Pick the style: Info for most things, Urgent for a cancellation or change, Celebration for the convention.
  6. Pick whether it shows once per visitor or every visit, and on the home page only or every page.
  7. Press Publish.

Each time you publish, the popup gets a new id by itself. Visitors who closed the old one will see the new one once.

Take it down

Turn On off and press Publish. It also stops by itself after the last day.

Dates

Dates are New Jersey dates, stored like 2027-01-02.

Pictures

A picture is optional. No people and no faces, and no personal phone numbers or addresses. Fill in the picture description too.

Saving

Press Publish at the top. The live site updates by itself in a minute or two. If you do not see the change, wait a moment and reload the page.
