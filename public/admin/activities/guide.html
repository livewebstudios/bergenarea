Activities events: how to use this editor

This editor changes the Activities events on the Events page, the Activities page and the home page. It cannot change anything else on the site.

Logging in

Bookmark this editor: /admin/activities/. Log in with the committee email and password you set from the invite email. The committee login is shared by whoever holds the position, so nobody's own name ever shows on the site or in its history.

Add an event

  1. Open Activities events.
  2. Press Add event. The new event appears at the top.
  3. Fill in the title and when it starts. Everything else is optional: fill in what you have.
  4. Press Publish.

Change an event

Open the event in the list, change what you need, and press Publish.

Remove an event

Open the event and press the small x on its row, then Publish. You only need this to take an event down early, for example when it is cancelled.

Past events

Events drop off the site by themselves once their end time passes (or their start time, if there is no end). They move to the archive at the bottom of the Events page. You do not need to delete them.

Dates and times

Pick the date and time in the box. Times are New Jersey time. The site stores them like 2027-06-12T12:00, which means June 12, 2027 at 12:00 noon. You never need to type a time zone.

Flyers

A flyer is optional. Flyers with personal phone numbers or addresses will not allowed to be posted on this website. No people and no faces in any picture. Fill in the flyer description too, so people who cannot see the picture still know what it says.

Saving

Press Publish at the top. The live site updates by itself in a minute or two. If you do not see the change, wait a moment and reload the page.
